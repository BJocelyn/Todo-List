# Todo List

A simple Todo List application built with React and Vite.

## Description

This project is a beginner React application that displays a list of todos. It uses JSX, React components, and JavaScript array methods to dynamically render todo items on the page.

## Installation

Clone this repository and install the project dependencies:

```bash
npm install
```

## Running the Development Server

Start the development server with:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

## Features

- Displays a list of todos.
- Uses React and JSX.
- Renders todo items dynamically using the JavaScript `map()` method.
